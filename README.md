# ry3-glitches

a collection of glitch sounds and ambiences from the sound designer [ry3](https://linktr.ee/Ry3Music) 

to use this inside of strudel, enter the following line in your strudel pattern:
```
samples('github:kyrsive/ry3-glitches')
```
